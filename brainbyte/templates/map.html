DATABASE: SYSTEM BASICS

01. SYSTEM INITIATION (TIER 1)

• The Print Command: Use print() to output data. For example, print(2 + 2) outputs 4.

• Variables: Created by assigning a value with = (e.g., x = 5). Python is Case-Sensitive, so myVar and myvar are different.

• Naming Rules: Names must start with a letter or underscore (_). They cannot start with a number or contain spaces. A variable can not have a name starting with a number.

• Comments: Use # for single-line notes. Use triple quotes ''' for multi-line logs.

• Code Blocks: Python uses Indentation (whitespace) to define blocks of code instead of brackets.

• Data Types: Common types are int (whole numbers), float (decimals), and str (text inside quotes like '123'). Use type() to check a variable's type.

• File Format: All Python scripts must use the .py extension.

02. DATA PROCESSING (TIER 2)

• Type Conversion: Change data types using int(), float(), or str(). Example: int('10') converts text to a number.

• System Input: The input() function always captures user data as a String, even if they type a number.

• String Tools: Use len() to get the number of characters. Access specific characters using Indexing: 'Python'[0] is 'P'.

• Floor Division: The // operator divides and rounds down to the nearest whole number (e.g., 10 // 3 = 3).

• Type Errors: You cannot add a String to an Integer directly (e.g., '5' + 5 causes an error).

• Special Characters: Use \n inside a string to create a New Line.

• Booleans: Represent True or False. Note that bool(0) is always False.

03. CORE LOGIC (TIER 3)

• Advanced Math: Use ** for exponents (e.g., 2 ** 3 = 8). Use % (Modulo) to find the Remainder of a division (e.g., 10 % 3 = 1).

• String Methods: Change case with .upper() or .lower(). Use .strip() to remove whitespace from the ends.

• String Slicing: Extract a range of characters with [start:end]. For example, 'Hello World'[0:5] is 'Hello'.

• F-Strings: The best way to format text: f"Age: {a}" inserts the variable a into the string.

• Sequence Operations: Use * to repeat strings (e.g., 'abc' * 3 is 'abcabcabc').

• Membership: Use in to check if a value exists inside a sequence (e.g., 'a' in 'apple' is True).

• Advanced Booleans: Any non-empty string is considered True, so bool('False') is actually True.

07. LIST PROTOCOLS (TIER 1)

• Definition: Lists are ordered collections that are Mutable (can be changed). Defined using square brackets: my_list = [1, 2, 3].

• Zero-Indexing: The first item is always at index 0. (e.g. my_list[0] retrieves the first element.).

• Length: Use len(my_list) to see how many items are stored in the sequence.

• Mixing Types: A single list can contain different data types, such as [1, "Data", 3.5].

08. SEQUENCE MODIFICATION (TIER 2)

• Appending: Use .append(item) to add a new element to the end of a list.

• Inserting: Use .insert(index, item) to place an element at a specific position.

• Removing: Use .remove(item) to delete the first occurrence of a value, or .pop() to remove the last item. In case of removing more items, you can abjust the variable inside .pop() to determinate the last item of your lists. (e.g. x = [2, 3, 4, 5], x.pop(1) the new x will be [2, 3])

• Clearing: Use .clear() to empty all the variables of a list.

• Copying: Use .copy() to make a new list.

09. TUPLE ENCRYPTION (TIER 3)

• Definition: Tuples are Immutable (cannot be changed after creation). Defined using parentheses: my_tuple = (1, 2, 3).

• Safety: Because they cannot be changed, tuples are faster and "safer" for data that should remain constant.

• Single Item: To create a tuple with one item, you must include a trailing comma: (5,).

• Nesting: Sequences can contain other sequences, creating "Nested Lists" or "Nested Tuples".
